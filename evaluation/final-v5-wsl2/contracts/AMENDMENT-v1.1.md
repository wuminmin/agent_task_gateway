# Final-V5 contract amendment v1.1

Previous contract release: `final-v5-contracts-v1`
(commit `1702e6514c71f3ce939f1197d05abacdf12a056f`, tag `final-v5-contracts-v1`,
preserved and never moved, overwritten, or deleted)

New contract release: `final-v5-contracts-v1.1`

## Defect

The Result-heavy Dataset Generator evaluated `row_id * 104729` as a PostgreSQL
`int4` multiplication. `generate_series(1, 100000)` yields `integer`, so the
product exceeds `2147483647` and raises `integer out of range` deterministically
from `row_id = 20504` onward. `ON_ERROR_STOP` then aborts the whole generator
transaction, so no deployment could ever materialize
`reporting.final_v5_result_heavy`, and therefore no Artifact cell could execute.

The defect was found while wiring the Result-heavy Product into a live
deployment, before any formal Publication Campaign was started.

## Correction

Promote `row_id` to `bigint` before the multiplication, so the product is
evaluated in the 64-bit domain the generator always intended:

```diff
-       ((row_id * 104729) % 10000000)::numeric / 10000,
+       ((row_id::bigint * 104729) % 10000000)::numeric / 10000,
```

This is the only change to any contract byte. `unit_price` is the only column
whose intermediate product could overflow `int4`; every other expression in the
generator was verified against live PostgreSQL 16 to stay inside `int4`.

## Semantic effect

None. No intended row count, field, value formula, generator seed, workload
cell, Catalog candidate, query contract, experiment matrix, Oracle semantics,
or Artifact cell definition changes. The previous generator could not
materialize the declared dataset at all; the corrected generator materializes
the originally intended values.

The independent Oracle already specified the intended values in 64-bit
arithmetic (`finalv5oracle.ArtifactRow` computes
`(rowNumber * 104729) % 10000000` as `int64`). The corrected generator is
therefore aligned with the Oracle that was frozen alongside it, and the
correction is confirmed by live Direct/Oracle equality for all six Artifact
shapes (100/10k/100k x 4/16).

## Publication evidence affected

None. No formal Publication Campaign was executed under `final-v5-contracts-v1`.
No Campaign ID exists, `TASKGATE_SUBMISSION_COMMIT` is unset, Stage D remains
closed with its `.NOT_READY` state retained, and no paper number was produced
from the defective generator.

## 教训(本会话新增,勿重蹈)

- buildkit RUN 步够不到 docker0 `172.17.0.1`,本机 proxy 必须绑 eth0 IP(会变,现查)。
- E1 运行期间动 worktree(pull)会使 build manifest commit 与 HEAD 不符而 verify 失败。
- `final-v5-profile-artifacts` 传绝对 `--registry` 而不传 `-root` 会把前导 `/` 吃掉。
- pgrep/pkill 一律用 `[x]` 方括号技巧防自匹配(本会话又犯了两次)。
- 远端长命令输出一律落远端文件再读,ssh 中继会随时断。
